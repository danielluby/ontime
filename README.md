# On-Time

This repository contains the source code for **On-Time**, a scheduling and financial control application for independent professionals. The project is built with a Node.js backend and a React frontend.

## Project Structure

```
backend/  - Node.js + Express API
frontend/ - React application
```

The project starts with a basic backend and a minimal React frontend. Future commits will expand features such as the calendar view, financial reports and integrations.

## Running the Backend

```
cd backend
npm install
npm start
```

Environment variables (see `.env.example`) must be configured to connect to a PostgreSQL database.

## Running the Frontend

```
cd frontend
npm install
npm run dev
```
