# On-Time

This repository contains the source code for **On-Time**, a scheduling and financial control application for independent professionals. The project is built with a Node.js backend and a React frontend.

## Project Structure

```
backend/  - Node.js + Express API
frontend/ - React application (not yet implemented)
```

The initial version contains only a minimal backend skeleton. Future commits will add more features such as a full calendar view, client management and financial reports.

## Running the Backend

```
cd backend
npm install
npm start
```

Environment variables (see `.env.example`) must be configured to connect to a PostgreSQL database.
